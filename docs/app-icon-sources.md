# 앱 아이콘 출처

- 여기어때 (`Web/icons/YEOGI.jpg`): GC COMPANY가 등록한 [한국 App Store 앱](https://apps.apple.com/kr/app/id884043462)의 아이콘. 2026-09-06 Apple Lookup API의 `artworkUrl512`에서 원본 JPEG를 받아 사용했다. 앱 ID는 884043462이며, 임의로 다시 그리거나 변형하지 않았다.
- 카카오뱅크·토스·KB스타뱅킹·케이뱅크: 기존 저장소 `data/icons/`의 아이콘을 앱 리소스에 복사했다.

아이콘이 없는 앱에는 브랜드를 흉내 낸 글자 그림 대신 중립적인 시스템 앱 기호를 표시한다.
